# Code of Conduct

## Our Pledge

We pledge to make participation in this project a respectful and harassment-free experience for everyone, regardless of age, body size, disability, ethnicity, gender identity and expression, level of experience, nationality, personal appearance, race, religion, sexual identity, or technology choices.

## Expected Behavior

- Be respectful and constructive.
- Assume good intent, but accept corrections when behavior causes harm.
- Keep discussions focused on the project and its technical goals.
- Give clear feedback without personal attacks.

## Unacceptable Behavior

- Harassment, intimidation, or discriminatory language.
- Insults, trolling, or sustained disruption.
- Publishing private information without explicit permission.
- Unwelcome sexual attention or imagery.

## Enforcement

Project maintainers may remove content, reject contributions, or restrict participation when behavior violates this code of conduct.

Report concerns privately through the maintainer contact listed in `SECURITY.md` or through GitHub repository moderation tools.

This code is adapted from the Contributor Covenant, version 2.1.
